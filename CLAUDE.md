# AdviseSlot: notes for AI agents

CPE 334 group project (Theme 1, office-hour advising bookings).

Before any git or GitHub action, read `docs/workflow.md` and follow it. In short:
branch from `sprint-N`, PR back into `sprint-N`, link the PR to its Issue, the
reviewer (not the author, not the agent) merges, and nothing is posted to GitHub
without the person reading it first.

Specs and decisions live in `docs/` (`srs.md`, `system-sds.md`, `decisions.md`).
